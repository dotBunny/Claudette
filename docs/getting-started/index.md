# Getting started

This chapter takes you from nothing to a working tab. It covers what Claudette needs, installing it (building it, on Linux), the first launch and signing in, opening your first tab, and a tour of the window. It ends with how Claudette uses Claude Code, so you know what is yours and what is Claude Code's, and how to run Claudette from its source.

Start with [What you need](what-you-need.md). On Linux, [Installing on Linux](installing-on-linux.md) has everything from start to finish. If Claudette is already installed, [A tour of the window](a-tour-of-the-window.md) names every part you see.
